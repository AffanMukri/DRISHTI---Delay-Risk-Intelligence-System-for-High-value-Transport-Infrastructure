# DRISHTI Interface System

## Direction

Professional civic intelligence: calm, evidence-led, precise, and accessible. The interface avoids decorative neon, excessive glass effects, and motion without meaning.

## Palette

- Ink: `#142f38`
- Deep civic blue: `#163f49`
- Primary teal: `#176b78`
- Operational teal: `#128277`
- Saffron accent: `#c68c35`
- Warm canvas: `#f6f4ef`
- Paper: `#fffefa`
- Border: `#dce3e1`
- Risk colors remain semantic and must never be the only indicator of meaning.

## Typography

- Interface/body: Aptos / Segoe UI Variable / system sans-serif.
- Major public and command headings: Charter / Iowan Old Style / Georgia serif.
- Numerical values use tabular numerals.
- Labels are concise, wrap safely, and retain readable contrast.

## Shape and depth

- Cards: 14-18px radius, quiet one-pixel border, restrained shadow.
- Controls: 10-12px radius with visible keyboard focus.
- Dense tables remain compact but use stronger row rhythm and hover state.

## Motion

- Text reveal is applied only to the public hero and uses word-level stagger.
- Page surfaces use short fade/translate entrances; controls use 160-240ms feedback.
- All continuous and entrance motion is disabled under `prefers-reduced-motion`.

## Accessibility and resilience

- Minimum 4.5:1 text contrast for normal text.
- No status is communicated using color alone.
- Long identifiers and labels may wrap without clipping.
- Verify layouts at 375px, 768px, 1024px, and 1440px.
